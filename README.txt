GRAVEWAKE - installable fullscreen version

Upload these 7 files (not the zip, and not a folder) to a free GitHub Pages site:
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, icon-maskable.png, apple-touch-icon.png

Then open the site in Chrome and choose "Add to Home screen" (or "Install app").
It opens fullscreen in landscape from its own icon and works offline after the first launch.

Moving your progress: in the old version tap Import / export > Copy,
then in the new app tap Import / export, paste, and tap Import pasted data.
